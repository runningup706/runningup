# RunningUp — 오너용 안내

이 파일 하나만 읽으면 됩니다. 나머지는 필요할 때만 보십시오.

---

## 이 앱이 뭔가

**실제로 달린 거리만이 힘이 되는 러닝 게임입니다.**

- 안드로이드 세로 화면, 고정 카메라 2.5D
- 한 달에 1,000km 를 향해 달리고, 체크포인트 121개를 지나 **World Crown** 으로 끝납니다
- 1,000km 위에는 아무것도 없습니다. 더 높은 등급도, 무한 사다리도 없습니다
- 8명이 겨루는 레이스가 기본이고, 50~100명이 참가하는 **Global Event** 가 따로 있습니다
- 계정당 **내 러너 한 명**. 그 한 명이 계속 자랍니다
- 돈·광고·출석·방치로는 핵심 성장이 **0** 입니다
- 전투는 없습니다. 보스도 몬스터도 HP 도 무기도 없습니다

앱 안의 글자는 **영어**, 오너에게 드리는 보고는 **한국어** 입니다.

## 화면 미리보기 — 어디서 보나

> **아직 준비 중입니다.** 만들어지면 이 자리에 링크가 들어갑니다.
>
> 준비되면 두 종류가 생깁니다.
>
> - **DESIGN PROPOSAL** — 실제 앱이 아니라 디자인 제안 그림입니다. 웹에서 바로 보입니다
> - **CURRENT UNITY RUNTIME CAPTURE** — 실제로 돌아가는 앱을 찍은 것입니다
>
> 이 둘은 항상 구분해서 표시합니다. 제안 그림을 실제 앱이라고 보여드리지 않습니다.

## 실제 앱으로 확인 — 어떻게 하나

안드로이드 고유 기능(GPS·헬스커넥트·뒤로가기·알림)은 **설치된 테스트 앱** 에서만 확인됩니다.
웹 미리보기에서는 그 기능들이 성공한 척하지 않고 `ANDROID DEVICE REQUIRED` 라고 표시합니다.

지금 이 부분은 **막혀 있습니다.**

> **APK 자동 빌드: 막힘.**
> Unity Personal 라이선스가 더 이상 CI 용으로 발급되지 않습니다.
> 예전에 쓰던 방법(수동 활성화 → 라이선스 파일)이 없어졌습니다.
>
> 길은 셋입니다.
> ① 오너 컴퓨터에서 직접 빌드 ② 전용 빌드 머신 ③ Unity Pro 구매(유료)
>
> 그동안에도 코드·데이터베이스·콘텐츠·검사·디자인 작업은 **계속 진행합니다.**
> 자동 검사가 초록불이어도 그건 "APK 가 만들어졌다"는 뜻이 아닙니다.
> 그래서 보고서에 다음 다섯 가지를 **따로** 적습니다.
>
> `WORKFLOW_SUCCESS` / `GATES_EXECUTED` / `UNITY_BUILD_EXECUTED` / `ARTIFACT_PRODUCED` / `DEVICE_TEST_EXECUTED`

## 오너만 하실 수 있는 일

기술적인 건 전부 제가 합니다. 다만 **다음 다섯 가지는 오너 본인만** 하실 수 있습니다.
계정과 결제와 되돌릴 수 없는 일이기 때문입니다.

1. 유료 서비스 가입·결제
2. 계정 로그인·비밀번호·2단계 인증·비밀키 입력
3. 실서비스 데이터 삭제
4. Play 스토어 정식 출시
5. 서명키·패키지명 변경

**지금 필요한 것** 은 [`CURRENT_STATE_KO.md`](CURRENT_STATE_KO.md) 맨 아래 `USER ACTION` 에만 적습니다.
그 줄이 비어 있으면 지금 오너가 하실 일은 없습니다.
