
# RUNNINGUP V11 제품 결정

## 최종 선택: 한 명의 My Runner + 60명의 Pacer

V10의 약 100명 플레이 캐릭터 구조를 그대로 유지하면 사용자의 애정이 여러 캐릭터로 분산되고, 높은 3D 품질을 맞추기 위해 캐릭터를 단순 복제할 위험이 크다. V11은 다음 하이브리드 구조를 정본으로 사용한다.

1. `My Runner`는 사용자가 수년간 계속 키우는 유일한 주인공이다.
2. 얼굴·피부색·헤어·체형·러닝 자세·의상·장비·오라·피니시를 꾸민다.
3. 실제 누적 러닝과 월간 성취에 따라 12단계 외형 진화를 한다.
4. `Pacer` 60명은 옆에서 달리는 동료·라이벌·스토리 캐릭터다.
5. Pacer와 Technique·Memory·Aura·Gear Blueprint 카드는 수집·합성·덱 전략을 담당한다.
6. 새 카드가 나와도 My Runner가 버려지지 않는다.

이 구조는 캐릭터 애착, 카드 수집, 3D 제작 품질, 장기 확장성을 동시에 확보한다.

## 실제 러닝 우선 경제

- 영구 핵심 성장과 대륙 주요 도약의 목표 기여도: 검증 러닝 85% 이상.
- 방치 진행: 배경 이동·공통 재료·작은 복구만 제공하며 주간 영구 진척의 약 5~10%로 제한.
- 메뉴 조작·반복 플레이: Fitness Core와 월간 km를 만들지 않는다.
- 구역 결승, My Runner 형태 진화, 월간 체크포인트는 검증 러닝이 필요하다.
- 하루 대표 콘텐츠는 `Daily Run Contract` 하나다. 추가 러닝은 정상 기본 보상을 계속 받지만 일일 숙제는 늘어나지 않는다.
