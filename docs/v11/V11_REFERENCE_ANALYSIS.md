
# 사용자 제공 게임 화면 분석과 V11 전환

## 1. 따뜻한 영웅 모집 공간
사용자 참고 이미지의 선술집 장면은 작은 캐릭터가 많이 배치되어도 각자의 실루엣과 행동이 읽히고, 불빛·음식·가구·말풍선으로 공간이 살아 있다는 장점이 있다. V11은 이를 `Runner Lounge`로 변환한다. 친구와 Pacer가 스트레칭하고 워치를 보며 대화하고, 이번 주·이번 달 러닝 거리가 말풍선과 테이블 보드에 나타난다.

## 2. 화면을 장악하는 대형 보스 연출
거대한 적과 오라의 장점은 목표가 즉시 이해되고 클라이맥스가 분명하다는 점이다. V11은 몬스터를 복제하지 않고 `Record Wall`, `Course Champion Hologram`, `World Crown Finish Gate`로 바꾼다. 사용자는 적을 때리지 않고 기록벽과 결승선을 돌파한다.

## 3. 카드 3장 공개 연출
중앙 카드가 크게 등장하고 등급별 프레임·빛·별이 다른 구조는 채택한다. V11에서는 Pacer·Technique·Memory 카드가 스타트 라인에서 등장하며, CROWN은 직접 뽑기가 아니라 승급과 World Crown 성취로 완성한다.

## 4. 장비 인벤토리의 밀도
슬롯 탭, 희귀도 테두리, 강화 수치, 비교 구조는 러닝화·워치·의류·이어폰·헤어밴드로 변환한다. 장착 즉시 My Runner 3D 모델에 반영되어야 한다.

## 5. 던전형 공간
격자 던전의 탐색감은 `Course Lab`, `Indoor Track`, `Crew Clubhouse`로 재설계한다. 검·몬스터·상자 약탈은 사용하지 않는다.

## 거부 항목
- 캐릭터·몬스터·아이콘·UI 배치의 직접 복제
- 전투 HP·피해 숫자·무기·공격
- 과도한 상품 아이콘과 빨간 점
- 캐릭터가 작고 배경에 묻히는 화면
- 단순 캡슐·졸라맨 형태의 최종 3D 캐릭터
