
# V11 핵심 루프

## 평소 앱을 열었을 때
Live Journey Home에서 My Runner가 현재 세계 코스를 계속 달린다. 방치 속도는 작고 부드럽다. 사용자는 이번 주 친구 거리, 다음 월간 체크포인트, 현재 대륙만 확인해도 된다.

## 현실에서 달렸을 때
RUN을 직접 기록하거나 승인된 출처에서 가져온다. 서버가 중복을 제거하고 검증한 뒤 `Stride Leap`을 실행한다. 3D 러너가 여러 코스를 빠르게 통과하고 대륙이 복구되며 My Runner의 외형·Pacer 유대·카드·장비 재료가 성장한다.

## 하루 콘텐츠
하루 대표 `Run Contract`는 하나만 보너스를 준다. Easy, Steady, Tempo, Interval, Long, Free 중 하나를 선택하고 난이도를 조정한다. 한 번 완료하면 오늘의 핵심 콘텐츠는 끝난다. 추가 러닝은 정상 기본 보상을 계속 받는다.

## 게임만 켜 둔 경우
Idle Drift는 공통 코인과 배경 복구를 조금 제공하지만, 구역 결승·월간 km·형태 진화·핵심 카드 승급을 열지 않는다. 반복 탭이나 레이스 재생으로 핵심 성장 재화를 무한 파밍할 수 없다.
