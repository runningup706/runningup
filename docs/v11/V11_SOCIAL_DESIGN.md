
# V11 소셜 설계

## Runner Lounge
따뜻한 3D 러너 클럽하우스다. 친구와 Pacer가 테이블·락커·스트레칭존에 배치되고, 말풍선에는 주간 거리·월간 거리·최근 완주가 표시된다.

## 친구 추가
- 친구 코드, QR, 초대 링크.
- 카카오톡은 공식 공유 링크와 딥링크를 우선 사용한다.
- 카카오 친구 목록 전체 접근을 가정하지 않는다.
- 연락처 매칭은 명시적 동의와 해시 매칭을 사용하며 원본 연락처를 보관하지 않는다.

## 공개 범위
비공개 / 친구 / 크루 / 전체 공개를 분리한다. 공개할 수 있는 항목은 주간·월간 거리, 현재 대륙, 연속일수, 선택한 기록이다. 원본 GPS 경로와 정확한 집 위치는 공개하지 않는다.

## 경쟁
실제 기록 랭킹, 개인 향상, 월간 거리, 크루 공동 거리, 가상 덱 리그를 분리한다. 카드·장비가 실제 러닝 기록 순위를 바꾸지 않는다.
